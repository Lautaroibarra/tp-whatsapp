# Clon de WhatsApp – Maquetación UI

##  Descripción

Este proyecto consiste en la **maquetación de la interfaz de usuario de un clon de WhatsApp**, realizada únicamente con **HTML y CSS**, sin utilizar JavaScript.

El objetivo principal es reproducir la **estructura, distribución, espaciados y apariencia general** de una aplicación de mensajería, tomando como referencia un layout con **sidebar de chats** y **panel de conversación**.

El proyecto forma parte de un trabajo práctico enfocado en el uso de **Flexbox**, organización del layout y buenas prácticas de versionado con Git.

## Objetivos del proyecto

* Reproducir visualmente la interfaz de WhatsApp Web.
* Aplicar maquetación en **dos columnas**.
* Practicar HTML semántico y CSS moderno.
* Trabajar con commits claros y descriptivos.

## Tecnologías utilizadas

* **HTML**
* **CSS**

> No se utilizó JavaScript

* Avatar de usuario

### Panel de conversación (columna derecha)

* Burbujas de mensajes:

  * Alineadas a la izquierda (mensajes recibidos)
  * Alineadas a la derecha (mensajes enviados)

## Control de versiones

El proyecto cuenta con un mínimo de **5 commits descriptivos**, siguiendo buenas prácticas:

Ejemplos de commits realizados:

* feat: estructura básica del layout
* layout: distribución de columnas con flexbox
* style: sidebar con avatar y lista de chats
* style: burbujas de mensaje alineadas y con colores
* refactor: mejoras en espaciados y estilos globales
